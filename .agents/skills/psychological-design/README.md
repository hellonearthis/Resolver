# Psychological Design Skill

A meta-craft framework and cognitive engineering engine for writing across **humor**, **poetry**, and **narrative prose**.

---

## 💡 Overview
Psychological design treats writing as a cognitive instruction set. Rather than focusing solely on *what* is written on the page, it engineers *how* a reader's mind processes:
- **Expectation:** Predictions, setups, subversions, and voltas.
- **Attention:** Focus, subtext, cognitive syntax, and environmental framing.
- **Identification:** Empathy, status play, and distance calibration.
