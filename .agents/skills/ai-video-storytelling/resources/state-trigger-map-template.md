# State/Trigger Map — Environment-Reactive Storytelling

Plan the emotional state machine BEFORE shot-listing. Shots get generated from this map, not the other way around.

---

## 1. Define the States

List every emotional mode a character or scene can occupy. Not plot beats — internal/relational states.

| State ID | Name | Description | Visual signature (concrete, not adjectives) |
|---|---|---|---|
| S1 | Raw conflict | Unfiltered tension, no audience | e.g. close framing, raised voice, no space between bodies |
| S2 | Guarded conflict | Aware they might be seen | e.g. lowered volume, increased physical distance |
| S3 | Performed calm | Mask fully on for a witness | e.g. relaxed posture, neutral face, eye contact avoided with each other |
| S4 | Aftermath | Alone again, mask drops | e.g. exhale, posture collapse, gaze drifts |

> Add/remove rows freely — this is the emotional vocabulary for your whole sequence.

---

## 2. Define the Triggers

What causes a jump from one state to another. Be specific — this becomes the literal action in your transition shot.

| Trigger ID | Event | From State → To State | Speed of transition |
|---|---|---|---|
| T1 | Third party enters the space | S1 → S3 | Instant (within 1 shot) |
| T2 | Third party leaves | S3 → S1 or S4 | Delayed (1-2s lag before mask drops) |
| T3 | Eye contact broken | S1 → S2 | Gradual |

> Instant vs gradual transitions are characterization — a slow bleed reads as exhaustion, an instant snap reads as practiced concealment.

---

## 3. State Sequence (the actual arc)

Chain states + triggers into the order they occur. This is your scene's real structure — plot-agnostic.

```
S1 (raw conflict)
  → [T1: third party enters] →
S3 (performed calm)
  → [T2: third party leaves, delayed] →
S4 (aftermath)
```

---

## 4. Handoff to Per-Shot Panel

For each State and each Trigger in your sequence, spin up one shot panel from the H3 Storyboard Template:

- **A State** = a shot (or short run of shots) holding steady in that emotional mode — acting note comes straight from the state's visual signature.
- **A Trigger** = its own shot — the transition IS the readable event for that time window. Camera/action field = the trigger itself (e.g. "third party enters frame, both characters' posture shifts within one beat").

This keeps your video from drifting: instead of improvising mid-shoot/mid-generation what a scene "feels like," you already decided where every emotional shift happens and what causes it.

---

## Notes
- Triggers don't have to be people — an environment change, a sound, a lighting shift, or a cut on the beat can all function as triggers.
- For dream-style/abstract cuts: you can cut AWAY from a trigger shot and return to the resulting state later (non-linear), since the state map still tells you which state a returning shot belongs to even out of sequence.
