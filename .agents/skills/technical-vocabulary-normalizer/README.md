# Technical Vocabulary Normalizer

## Overview
This skill normalizes fuzzy, poetic, or informal terminology often used in architectural ideations into precise, standard technical vocabulary. It helps translate abstract concepts into actionable engineering terms.

## How to Use
Provide an informal architectural description, diagram text, or ideation, and ask the agent to normalize it.

**Example Prompts:**
- "Normalize this architecture description: 'We need a big bucket to hold all the user photos before they get squished and sent to the front end.'"
- "Translate this poetic system design into standard technical vocabulary."

## What to Expect
You will receive a revised description replacing informal terms (like "bucket" or "squish") with precise engineering terms (like "Object Storage," "S3," or "Image Compression").
