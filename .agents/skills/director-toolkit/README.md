# Director Toolkit Skill

A craft-level reference for cinematic staging, visual grammar, camera optics, lighting architecture, and sound design. Organized around a bank of nameable techniques ("moves"), modular director style profiles, and environment-reactive staging.

---

## 🚀 Key Features

1. **The 4 Core Directing Modules:**
   - **Camera:** Shot scale (ECU to EWS), lens physics (14mm ultra-wide to 135mm telephoto), movement grammar, and cutting rhythms.
   - **Lighting:** Contrast ratios (high-key vs. chiaroscuro), source quality (hard vs. diffused), color temperature (3200K tungsten to sodium vapor), and motivated practicals.
   - **Blocking & Composition:** Dead-center symmetry vs. canted asymmetry, Z-axis foreground/background layering, and body count dynamics.
   - **Sound & Atmosphere:** Acoustic layering over volume, diegetic vs. score, domestic room tone beds, and silence as a kinetic weapon.

2. **Director Style Profiles & Cross-Pollination:**
   - **Wes Anderson:** Symmetrical control-freak precision, flat pastel palettes, 90° whip-pans.
   - **Terry Gilliam:** Bureaucratic grotesque, 14mm ultra-wide facial distortion, canted Dutch tilts, institutional clutter.
   - **James Cameron:** Industrial kinetic dread, emergency sodium-amber/cyan clashes, hydraulic machinery sound beds.
   - **80s Broadcast / BBC Prestige:** Somatic restraint, motorized optical zooms, tungsten halogen practicals, conversational latency.
   - **Profile Blending:** Combine aesthetic parameters (e.g. *Anderson symmetry + Cameron industrial dread*).

3. **Reactive Staging Layer:**
   - Moves the dramatic needle through environmental changes (background disruptions, light failures, acoustic drops) rather than dialogue exposition.

4. **The Named Moves Bank:**
   - Modular, queryable techniques: *"The Held Wide"*, *"The Symmetrical Dead-Center"*, *"The Sodium Flicker"*, *"The Bureaucratic Fluorescent"*, *"The Optical Creep"*, *"The Dropped Score"*.

5. **Psychological Moves Matcher & Counter-Intuitive Inversions:**
   - Matches internal scene tension (containment, status slip, denial) with unexpected visual choices (e.g. pastel symmetry for profound grief) using the `/grill-me` protocol.

---

## 🎬 How to Use

Invoke this skill whenever you are planning a scene, directing video prompts, or designing a storyboard:

* *"How should I light and block a tense interrogation scene using director-toolkit?"*
* *"/grill-me on matching director moves for a high-stakes conspiracy scene."*
* *"Give me an outside-the-box psychological camera move for a character in denial."*
* *"Stage an argument using Anderson symmetry blended with Cameron industrial lighting."*
* *"Compile a MiniMax H3 prompt using the 80s Broadcast somatic restraint profile."*
